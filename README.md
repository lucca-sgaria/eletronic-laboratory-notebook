# Eletronic Laboratory Notebook
## Computer Science Bachelor's Degree Final Project

Project that started being designed during the first semester of 2022 and is planned to be completed at the end of 2022.

The main goal is to build an Eletronic Laboratory Notebook (ELN) prototype using [Quarkus](https://quarkus.io/) (Java) as the Back-End framework and [React](https://reactjs.org/) as the Front-End framework.
